# Главная: точки входа как 3 альтернативы (колонки + дивайдеры) — дизайн-документ

**Дата:** 2026-07-18 · **Репо:** `glmelnik96/SLIDES_APK`, ветка `feat/uxui-redesign` · **Область:** главная, секция «С чего начать».

## Глубокий анализ (проблемы «куда и зачем жать»)
1. **«План 1-2-3».** Номера 01/02/03 читались как последовательные шаги, хотя это **три альтернативных способа — выбрать нужно один**. → убрать номера, ввести фрейм выбора.
2. **Неясно «зачем жать».** Было только «что это», без критерия выбора. → к каждому способу добавить «когда подойдёт».
3. **Текст столбиком, нет структуры.** → колонки + 1px-дивайдеры.
4. **Иерархия.** «Загрузить документ» — основной путь (форма прямо тут), два других — тихие альтернативы; один яркий primary на экран.

## Решение
- **Заголовок-фрейм:** eyebrow «С чего начать» + лид «Три способа сделать презентацию — выберите один, смотря что у вас уже есть.» (позиционирует как выбор, не шаги).
- **Основной блок — «Загрузить документ»** (`.entry-zone--primary`, акцентная рамка):
  - `.entry-zone__head` — «Загрузить документ» + приглушённое «когда есть готовый текст или документ», отделён `border-bottom`.
  - `.upload-grid` — двухколоночное тело: **dropzone │ (1px дивайдер) │ «Точный перенос» + «Создать презентацию»**.
- **Два способа вручную — `.entry-alts`** (общая рамка), каждый — строка-грид `.entry-alt` с колонками через `border-left`-дивайдеры: **название │ описание │ «когда подойдёт» │ действие**; строки разделены `border-top`.
  - «Собрать в чате» — «когда нет готового материала» — ссылка «Открыть чат →».
  - «Заполнить шаблон» — «когда нужен полный контроль» — ссылка «Открыть конструктор →».
- **Действия:** primary — залитая «Создать презентацию» (в блоке загрузки); альтернативы — тихие акцентные ссылки (не крупные кнопки). Номера 01/02/03 удалены.
- Адаптив ≤760px: колонки складываются, дивайдеры-`border-left` → `border-top`.

## Поведение (JS без изменений)
`#create` — загрузка/сборка; `#openChat`/`#openManual` → `startDraft(mode)` → `/editor?…&mode=…`. Ids не менялись.
