# Главная: блок «С чего начать» → горизонтальный ряд карточек — дизайн-документ

**Дата:** 2026-07-18 · **Репо:** `glmelnik96/SLIDES_APK`, ветка `feat/uxui-redesign` · **Область:** главная страница раздела «Слайды».

## Проблема
После правки К§9 карточка 01 «Загрузить документ» стала доминирующей (форма загрузки сразу под ней), а «Заполнить шаблон» и «Собрать в чате» задвинуты вниз под подпись «Другие способы» в узкой левой колонке и читались как второстепенные — **не очевидно, что эти функции есть**.

## Решение (итог)
Рассматривали вариант с табами — **отклонён** по решению заказчика. Итоговое решение: **три равноправные карточки в горизонтальный ряд на всю ширину**, над двухколоночной рабочей областью. Поведение — как в исходном варианте (не табы): карточка «Загрузить» раскрывает форму загрузки под собой; «Собрать в чате» / «Заполнить шаблон» открывают редактор по клику.

## Структура
- Секция `.entry` вынесена из узкой `.workspace__controls` на **всю ширину** (`.wrap`, max 1240px), сразу после интро.
- `.entry-cards` — грид `repeat(3, 1fr)` (базовый стиль; переопределение `.workspace__controls .entry-cards { 1fr }` больше не применяется, т.к. `.entry` не в колонке). Три карточки:
  1. **01 «Загрузить документ»** (`.entry-card--primary`, акцентная рамка/фон) — CTA «Выбрано — загрузите файл ниже ↓».
  2. **02 «Собрать в чате»** — CTA «Открыть чат →».
  3. **03 «Заполнить шаблон»** — CTA «Открыть конструктор →».
- Ниже — двухколоночный `.workspace`: слева `.workspace__controls` с `#uploadFlow` (dropzone + «Точный перенос» + «Создать презентацию»), справа `.workspace__output` (пустое состояние / прогресс / результат / черновики / история).
- На `≤720px` карточки складываются в столбик (существующий `@media`).

## Поведение (без изменений в JS)
- Карточка «Загрузить документ» (`data-entry="upload"`, `is-active` по умолчанию): клик показывает `#uploadFlow` + скролл. Форма и так видима по умолчанию (upload — единственный инлайн-режим).
- «Собрать в чате» / «Заполнить шаблон»: клик → `startDraft(mode)` → `POST /api/drafts` → `location.href = /editor?session=…&mode=…`. Логика карточек (`.entry-card` onclick, `startDraft`, `ENTRY_CTA`, `pageshow`) — исходная, не менялась.

## Затронутые файлы
- `webapp/static/index.html` — `.entry` вынесена на всю ширину над `.workspace`; порядок карточек upload → chat → manual; `#uploadFlow` перенесён в `.workspace__controls`; убрана подпись «Другие способы».
- `styles.css` / `app.js` — **изменений не потребовалось** (базовый `.entry-cards` уже `repeat(3,1fr)`; card-логика прежняя).

## Проверка
Визуальная QA на стенде (`:8020`): три карточки в ряд на всю ширину, порядок 01/02/03 = Загрузить/Чат/Шаблон; клик «Собрать в чате» → чат-редактор (проверено); форма загрузки и черновики/история ниже; узкая ширина складывает в столбик. Регрессия `pytest` не затрагивается.
