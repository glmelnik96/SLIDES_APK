# Главная: зоны точек входа (Вариант 3 «загрузка-герой») — дизайн-документ

**Дата:** 2026-07-18 · **Репо:** `glmelnik96/SLIDES_APK`, ветка `feat/uxui-redesign` · **Область:** главная страница раздела «Слайды».

## Проблема
Точки входа (загрузка / чат / шаблон) и черновики визуально смешивались: карточки в ряд сверху, а форма загрузки и черновики стояли рядом в двухколоночной области — «черновики заходят на зону загрузки», нелогично.

## Критерии (от заказчика)
1. Каждый элемент — в своей зоне, зоны не смешиваются.
2. Все функции видны на одном экране (загрузка, чат, шаблон).
3. Порядок зон по приоритету: 1-загрузка → 2-чат → 3-шаблон → 4-черновики.

## Решение (Вариант 3 «загрузка-герой»)
Рассматривали также вертикальный стек (В1) и «функции слева / черновики справа» (В2). Выбран **В3**:
- **Верх — грид `1.6fr / 1fr`:**
  - **Зона 1 · «Загрузить документ»** (`.entry-zone--primary`, акцентная рамка/фон) — крупная зона-герой слева: заголовок + описание + `#uploadFlow` (dropzone → «Точный перенос» → «Создать презентацию»).
  - Справа стеком — **Зона 2 · «Собрать в чате»** (кнопка «Открыть чат») и **Зона 3 · «Заполнить шаблон»** (кнопка «Открыть конструктор»); обе тянутся по высоте под зону 1, кнопки прижаты к низу.
- **Ниже во всю ширину — Зона 4 · выдача** (`.output`): пустое состояние, прогресс, результат, черновики, очередь, история.

Каждая функция — в отдельной обведённой зоне; приоритет читается размером и порядком (герой → компактные → выдача снизу).

## Поведение
- Зона 1: форма загрузки как есть; «Создать презентацию» — существующая логика.
- Зоны 2/3: кнопки `#openChat` / `#openManual` → `startDraft(mode)` → `POST /api/drafts` → `/editor?…&mode=…`. Черновик создаётся только по кнопке (клика по «карточке» больше нет — нет случайных осиротевших черновиков).

## Затронутые файлы
- `webapp/static/index.html` — `.entry-hero` (зона-герой + `.entry-side` со стеком зон 2/3); выдача вынесена в `<section class="output">` во всю ширину (убран `.workspace`-грид).
- `webapp/static/styles.css` — `.entry-hero/.entry-side/.entry-zone/.entry-zone--primary/.entry-zone__title/__desc/__btn/.output` + брейкпоинт ≤860px (герой в один столбец).
- `webapp/static/app.js` — `startDraft` работает с обычной кнопкой; обработчики `#openChat`/`#openManual`; `pageshow` сбрасывает эти кнопки. Логика загрузки/сборки не менялась.

## Проверка
Визуальная QA на стенде (`:8020`): три зоны раздельно, загрузка-герой слева, чат/шаблон справа, черновики во всю ширину снизу; всё на одном экране; клики «Открыть чат/конструктор» уводят в редактор. Регрессия `pytest` не затрагивается.
