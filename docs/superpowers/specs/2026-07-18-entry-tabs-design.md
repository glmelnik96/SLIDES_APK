# Главная: блок «С чего начать» → табы — дизайн-документ

**Дата:** 2026-07-18 · **Репо:** `glmelnik96/SLIDES_APK`, ветка `feat/uxui-redesign` · **Область:** главная страница раздела «Слайды», левая колонка `.workspace__controls`.

## Проблема
После правки К§9 карточка 01 «Загрузить документ» стала доминирующей (форма загрузки сразу под ней), а два других режима — «Заполнить шаблон» (конструктор) и «Собрать в чате» — задвинуты вниз под подпись «Другие способы» и читаются как второстепенные. Пользователю **не очевидно, что эти функции вообще есть**. Плюс сохраняется старая проблема: случайный клик по карточке 02/03 мгновенно создаёт невидимый осиротевший черновик.

## Решение
Заменить блок «карточка 01 + задвинутые 02/03» на **горизонтальный таб-бар из трёх равноправных табов**. Клик по табу переключает панель под ним; переход в редактор — только по явной кнопке в панели (черновик создаётся тогда же).

## Структура

**Таб-бар** (наверху блока, вместо `.entry-cards` + «Другие способы»):
- Три таба: **«Загрузить»**, **«Заполнить шаблон»**, **«Собрать в чате»**.
- Активный подчёркнут акцентом — тот же приём, что уже есть у `.topnav__link.is-active` (топбар) и `.rpanel-tab.is-active` (панель редактора). Прямые углы, бренд-токены, `--track-caps` не нужен (это не капс-лейбл, а таб-навигация).
- По умолчанию активен **«Загрузить»** (сохраняем нынешний основной флоу).
- Узкая колонка (~340–420px): таб-бар — `display:flex`, подписи при нехватке места переносятся/чуть уменьшаются (`flex:1`, `white-space:normal`, минимальный кегль ≥ `--fs-sm`), но не обрезаются.

**Панели под табами** (одна видима за раз, `.hidden` на скрытых):
1. **«Загрузить»** → существующий `#uploadFlow` без изменений содержимого: dropzone (`#drop`), «Точный перенос (1 в 1)», кнопка «Создать презентацию» (`#create`) + хинт. Просто переезжает внутрь панели таба.
2. **«Заполнить шаблон»** → короткое описание + кнопка **«Открыть конструктор»** (`.btn btn-accent`):
   > «Соберите презентацию из готовых макетов вручную: добавляйте слайды, выбирайте макет и заполняйте поля. Справа — чат для точечных правок.»
3. **«Собрать в чате»** → описание + кнопка **«Открыть чат»** (`.btn btn-accent`):
   > «Опишите презентацию ассистенту — он спланирует структуру и создаст слайды по одному. Дальше правьте текст и оформление прямо в браузере.»

## Поведение
- Клик по табу: только `activate(tab)` — снять/навесить `.is-active` на таб, показать соответствующую панель, скрыть остальные (`.hidden`). **Никакой навигации и создания черновика.**
- Кнопка «Открыть конструктор» / «Открыть чат»: ровно нынешняя логика карточек 02/03 — `POST /api/drafts {mode}` → `location.href = /editor?session=…&mode=…`. Черновик создаётся **только здесь**.
- `data-entry`-обработчики карточек заменяются: таб-переключение отдельно от кнопок-открытия. Существующие id (`#drop`, `#file`, `#create`, `#exactTransfer`, `#uploadFlow`) сохраняются — логика загрузки и `app.js` не ломаются.

## Доступность
- Семантика: контейнер `role="tablist"`, табы `role="tab"` + `aria-selected` + `aria-controls`; панели `role="tabpanel"` + `aria-labelledby`; неактивные табы `tabindex="-1"`, активный `tabindex="0"`.
- Клавиатура: ←/→ переключают табы (roving tabindex), Enter/Space активируют, focus-visible кольцо (как С§4).

## Что не меняется
Интро; правая колонка (`workspaceEmpty`, `progress`, `result`, `draftsWrap`, `activeWrap`, история); «Точный перенос»; серверная часть; логика `#create`/сборки.

## Что убирается
Подпись «Другие способы»; нумерация табов «01/02/03» (табы называют себя сами); классы `.entry-card--primary`/`is-active` в прежнем виде (заменяются таб-состоянием). Само название блока «С чего начать» (`.eyebrow`) можно оставить как заголовок над таб-баром.

## Затрагиваемые файлы (изолированно)
- `webapp/static/index.html` — перестройка `.entry` (tablist + 3 tabpanel; `#uploadFlow` внутрь первой панели; описания+кнопки во второй/третьей).
- `webapp/static/styles.css` — стили `.entry-tabs`/`.entry-tab`/`.entry-panel` (переиспользуют существующий таб-приём и токены).
- `webapp/static/app.js` — тумблер табов (~15 строк) + перенос логики открытия конструктора/чата с `data-entry`-карточек на кнопки панелей; `ENTRY_CTA`/pageshow-обработчик упростить (карточек-состояний больше нет).

## Тест/проверка
Визуальная QA на стенде (`:8020`): три таба, дефолт «Загрузить» с формой; переключение показывает описания+кнопки без навигации; «Открыть конструктор/чат» создают черновик и открывают редактор; ←/→ и focus-ring работают; узкая колонка не ломается. Регрессия `pytest` зелёная (фронт не влияет).
