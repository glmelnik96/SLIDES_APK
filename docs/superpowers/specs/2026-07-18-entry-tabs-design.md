# Главная: точки входа как 3 альтернативы (колонки + дивайдеры) — дизайн-документ

**Дата:** 2026-07-18 · **Репо:** `glmelnik96/SLIDES_APK`, ветка `feat/uxui-redesign` · **Область:** главная, секция «С чего начать».

## Глубокий анализ (проблемы «куда и зачем жать»)
1. **«План 1-2-3».** Номера 01/02/03 читались как последовательные шаги, хотя это **три альтернативных способа — выбрать нужно один**. → убрать номера, ввести фрейм выбора.
2. **Неясно «зачем жать».** Было только «что это», без критерия выбора. → к каждому способу добавить «когда подойдёт».
3. **Текст столбиком, нет структуры.** → колонки + 1px-дивайдеры.
4. **Иерархия.** «Загрузить документ» — основной путь (форма прямо тут), два других — тихие альтернативы; один яркий primary на экран.

## Решение
- **Интро-очистка:** убраны eyebrow «Слайды» (дублировал таб топбара), зелёный глиф `.intro-title::before` перед h1 и вводный абзац — описание переехало под `<details>` «Подробнее». Заголовок остаётся флаг-левым без padding.
- **Заголовок-фрейм:** eyebrow «С чего начать» + лид «Три способа сделать презентацию — выберите один, смотря что у вас уже есть.» — **во всю ширину** (снят `max-width: 62ch`, чтобы не переносил «уже есть»).
- **Основной блок — «Загрузить документ»** (`.entry-zone--primary`, акцентная рамка):
  - `.entry-zone__head` — «Загрузить документ» + «когда есть готовый текст или документ» **в правом углу** (`margin-left: auto`), отделён `border-bottom`.
  - `.upload-grid` (1.5fr 1fr) — тело: **dropzone │ (1px дивайдер) │ «Точный перенос» + «Создать презентацию»**; опции прижаты к **верху** (`justify-content: flex-start`).
- **Два способа вручную — `.entry-alts`** (общая рамка), каждый — строка `.entry-alt` **той же сеткой 1.5fr 1fr** и теми же отступами дивайдера, что `.upload-grid`/`.upload-side` → **все три вертикальных дивайдера совпадают по X** (проверено: 847px). Слева `.alt-main` (название+описание), справа за дивайдером `.alt-aside` («когда подойдёт» + подсказка-действие).
  - «Собрать в чате» — «когда нет готового материала» — «Открыть чат →».
  - «Заполнить шаблон» — «когда нужен полный контроль» — «Открыть конструктор →».
- **Клик по всей рамке:** `.entry-alt` — `role="button"`/`tabindex="0"`/`data-mode`, обработчик click+Enter/Space → `startDraft`. Ссылка `.entry-open` — `pointer-events: none` (визуальная подсказка, клик ловит рамка).
- **Черновики и История сборок — рядом в две колонки** (`.history-grid`, класс `two-col` ставит `loadDrafts()` только когда черновики есть; иначе История во всю ширину). Подзаголовки `.hist-sub` объясняют разницу: черновики = начатые-несобранные, история = готовые (24 ч). «Активные сборки» — над сеткой, во всю ширину.
- Адаптив ≤760px: колонки складываются, дивайдеры-`border-left` → `border-top`; сетка История → одна колонка.

## Поведение (JS)
`#create` — загрузка/сборка. Точки входа: клик/Enter/Space по всей `.entry-alt[data-mode]` → `startDraft(mode, .entry-open)` → `/editor?…&mode=…` (гард `data-busy` от дабл-клика). `loadDrafts()` переключает `#historyGrid.two-col`. Ids `#openChat`/`#openManual` сохранены (теперь на span — для сброса по `pageshow`).

## Файлы
- `webapp/static/index.html` — интро (без eyebrow/абзаца, описание в `<details>`), секция `.entry` (`.entry-zone--primary` + `.entry-alts`/`.entry-alt` с `.alt-main`/`.alt-aside`), `.history-grid` (Черновики │ История).
- `webapp/static/styles.css` — `.intro-title` (глиф удалён), `.entry-lead` (full-width), `.entry-when` (right), `.upload-side` (flex-start), `.entry-alt`/`.alt-main`/`.alt-aside` (1.5fr 1fr + клик-состояния), `.history-grid`/`.hist-sub` + адаптив.
- `webapp/static/app.js` — делегированный клик по `.entry-alt`, `two-col` в `loadDrafts()`.

## Проверка
Визуальная QA (`:8020`): дивайдеры трёх блоков на одном X (847px, измерено); лид в одну строку; «когда» в правом углу загрузки; «Точный перенос» у верха; клик по всей рамке (span pointer-events:none, hit-test → рамка); Черновики │ История в две колонки. `pytest` 284 зелёных, node-тесты 8 зелёных.
