# Главная: зоны точек входа (вертикальный стек, компактно) — дизайн-документ

**Дата:** 2026-07-18 · **Репо:** `glmelnik96/SLIDES_APK`, ветка `feat/uxui-redesign` · **Область:** главная страница раздела «Слайды».

## Критерии (от заказчика)
1. Каждый элемент — в своей зоне, зоны не смешиваются.
2. Все функции видны на одном экране (загрузка, чат, шаблон), + черновики.
3. Приоритет: 1-загрузка → 2-чат → 3-шаблон → 4-черновики.
4. Компактно; действия-кнопки не должны перетягивать внимание.

## Итоговое решение (Вариант 1, компактный)
Перебрали: табы (отклонено), горизонтальный ряд карточек, «загрузка-герой + сайдбар» (В3). Финал — **вертикальный стек зон по приоритету**, компактно:
- **Зона 1 · «Загрузить документ»** (`.entry-zone--primary`, акцентная рамка/фон) — единственная «крупная» зона: заголовок + `#uploadFlow` (dropzone → «Точный перенос» → «Создать презентацию»).
- **Зона 2 · «Собрать в чате»** и **Зона 3 · «Заполнить шаблон»** — **компактные строки** (`.entry-zone--row`): номер + название + описание слева, **сдержанная акцентная ссылка-действие** справа («Открыть чат →» / «Открыть конструктор →») — НЕ крупная залитая кнопка, чтобы не перетягивать внимание с основного сценария (загрузки).
- **Зона 4 · выдача** (`.output`, во всю ширину снизу): пустое состояние, прогресс, результат, черновики, очередь, история.

Один визуальный «primary» на экране — залитая «Создать презентацию» в зоне 1; вторичные действия — тихие ссылки (в духе Р§4 «одна залитая на группу»).

## Поведение
- Зона 1: форма загрузки как есть.
- Зоны 2/3: ссылки-кнопки `#openChat` / `#openManual` → `startDraft(mode)` → `POST /api/drafts` → `/editor?…&mode=…`. Черновик создаётся только по явному действию.

## Затронутые файлы
- `webapp/static/index.html` — `.entry-stack` (герой + две `.entry-zone--row`); выдача в `<section class="output">`.
- `webapp/static/styles.css` — `.entry-stack/.entry-zone/.entry-zone--primary/--row/.zone-text/.entry-open/.output`; уменьшены паддинги; ≤640px — строки в столбик.
- `webapp/static/app.js` — `startDraft` (обычная кнопка/ссылка) + обработчики `#openChat`/`#openManual` + сброс на `pageshow`.

## Проверка
Визуальная QA (`:8020`): три зоны раздельно, вертикально по приоритету; чат/шаблон — компактные строки со сдержанными ссылками; черновики/история во всю ширину; клики уводят в редактор. `pytest` не затрагивается.
