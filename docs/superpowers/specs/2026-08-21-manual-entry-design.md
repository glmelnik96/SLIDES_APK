## Реальные пробелы (по прогону, не по слухам)

1. Пустой старт: голое «Слайдов пока нет» — паралич чистого листа.
2. Пикер тяжёлый: 22 живых full-deck iframe, простыня ~3000px без групп;
   на слабых машинах тормозит (рендерер таймаутил скриншоты при прогоне).
3. Бейдж «15 типов на выбор» на плитке «Схема» вклеен в текст криво.
4. Вход на главной выключен флагом (`.is-disabled` + app.js не вешает клик).

## Решения

### 1. Скелет при создании (сервер)

`POST /api/drafts {mode:"manual", skeleton:true}` → план сразу с тремя
слайдами `cover` → `blank` → `contacts`, content пустой (коэрсия превью уже
показывает плейсхолдеры). Флаг шлёт ТОЛЬКО новая кнопка входа: glass строит
план сам через `glass/start`, существующие вызовы и тесты не задеты.

### 2. Пустое состояние (клиент)

Слайдов 0 (всё удалили) → вместо мелкой кнопки: короткая подсказка + две
крупные: «Начать со структуры» (клиентские POST тех же трёх слайдов) и
«Выбрать макет» (пикер). Канон v5.

### 3. Пикер: группы + статичные PNG-превью

- Сервер: `GET /api/templates/{id}/thumb?theme=dark|light` — PNG-миниатюра
  (существующая Playwright-скриншотилка по той же одностраничной деке, что в
  iframe-превью). Кэш `data/tpl-thumbs/{id}-{theme}.png`, генерится лениво
  при первом запросе, инвалидация по mtime `library.json`.
  Chromium недоступен → 404 → клиент падает обратно на live-iframe
  (текущее поведение). Деградация мягкая.
- Клиент: грид группами — «Обложки и финал» (cover, cover-image, contacts),
  «Цифры и графики» (kpi, kpi-row, bar/donut/line/stacked, kpi-rings),
  «Сравнение и структура» (before-after, timeline, diagram),
  «Текст и карточки» (accent×2, quote, service-table, two-cards,
  three-columns, tile/frame-grid, blank). Плитка = `<img>` вместо iframe;
  бейдж «15 типов» — нормальный элемент плитки (фикс вёрстки). Пикер типов
  схем — тем же способом.

### 4. Точка входа на главной

Снять `is-disabled` с карточки «Заполнить шаблон» (index.html), повесить
клик в app.js: `POST /api/drafts {mode:"manual", skeleton:true}` →
`/editor?session=…&mode=manual`. «Собрать в чате» остаётся заглушенной.
Тексты карточки сверить с реальностью.

## Тесты и верификация

- pytest: скелет с флагом есть / без флага нет; thumb-эндпоинт — кэш,
  повторный запрос из кэша, 404 при недоступном Chromium.
- JS: группировка каталога — чистая функция + node --test.
- e2e preview: главная → карточка → редактор со скелетом → пикер с PNG →
  заполнение → скачать HTML.
- Прод: thumb-рендер проверять в sandbox-контексте юнита (ProtectHome;
  Chromium уже в `/opt/app2/.playwright`).

## Риски

- Перф/доступность thumb-рендера на проде — закрыт мягким fallback на
  live-iframe.
- Скелет не должен просочиться в glass-путь — закрыт явным opt-in флагом.
