# Расширенные цвета графиков + правило «≤3 цвета на слайд» — дизайн

**Дата:** 2026-07-15
**Статус:** черновик на согласовании
**Ветка:** template-picker

---

## В двух словах (для не-технического ревью)

Сейчас все графики **одноцветные**: зелёный + «лесенка прозрачности» (сегменты
разной прозрачности одного зелёного). Из бренд-гайда просили добавить
дополнительные цвета — но дозированно, без «радуги».

Итог договорённости:
- **Общее правило для всей системы:** на одном слайде — не более **3 хроматических
  (цветных) цветов**; всё сверх этого различаем **оттенками этих цветов и серой
  шкалой**.
- **Композиционные графики** (кольцо-доли `donut`, составные бары `stacked-bar`,
  гистограмма-сравнение `bar-chart`) получают палитру: **зелёный-герой + до 2
  приглушённых доп-цветов + оттенки серого**.
- **Метрики/тренды** (`kpi`, `stats-row`, `kpi-rings`, `line-chart`) **остаются
  зелёными** — там цвет не нёс бы смысла.
- Мёртвые бренд-цвета **magenta и aqua убираем**.

Зелёный всегда доминирует по массе; доп-цвета приглушены и уступают; хвост уходит
в нейтральный серый. Превью-рендеры согласованы (`_shots/palette_schemes_dark.png`).

## Мотивация / контекст

- Запрос пользователя: добавить доп-цвета Cloud.ru 2.0 в графики и «использовать
  цвета по назначению — во всей системе, не только в графиках»; завести гайды.
- Ограничение, сформулированное по ходу: **сдержанность важнее пестроты**. Поэтому
  вместо «5 разных цветов на donut» — правило ≤3 хроматических + серый.
- Все расширенные токены в `deck.css` сейчас **мёртвые** (объявлены, не
  используются), поэтому раскраска графиков — «с чистого листа», риск регрессий
  низкий.

---

## Правило раскраски (общесистемное)

> На одном слайде допускается **не более трёх хроматических цветов**. Для
> дальнейшей дифференциации используются только **оттенки/тинты этих цветов** и
> **нейтральная серая шкала**. Зелёный `#26D07C` — всегда цвет-герой и держит
> доминанту по массе. Насыщенные («активные») доп-цвета — только для обводок и
> точечных акцентов, **не** для заливки графиков.

Это правило **заменяет** прежний инвариант «графики одноцветные — без радуги».

## Токены (`deck.css`)

### Новые токены серии графиков (резолвятся темой)

Семантические `--chart-1..6`, потребляются шаблонами по индексу сегмента.
`--chart-1` (зелёный-герой) одинаков в обеих темах; остальные — по теме.

| Токен | Роль | dark | light |
|---|---|---|---|
| `--chart-1` | зелёный-герой | `#26D07C` | `#26D07C` |
| `--chart-2` | ultramarine приглушённый | `#5D779F` | `#9CADCE` |
| `--chart-3` | purple приглушённый | `#8372A1` | `#BDB0D2` |
| `--chart-4` | серый gray3 | `#989898` | `#A6A6A6` ¹ |
| `--chart-5` | серый gray4 | `#737373` | `#8C8C8C` ¹ |
| `--chart-6` | серый gray5 | `#525252` | `#737373` ¹ |

¹ Значения серого для **светлой** темы — стартовое предложение; подбираются на
светлом рендере так, чтобы серые **уступали** пастельным доп-цветам (не
перетяжеляли иерархию). Тёмные значения — согласованы.

Реализация: `--chart-1: var(--cl-green)` в `:root`; `--chart-2..6` — литералами в
блоках `html[data-theme="dark"]` / `html[data-theme="light"]`, рядом с комментом-гайдом.

### Удаляем (мёртвые)

- `--cl-magenta` (`#FF00FF`), `--cl-aqua` (`#18F4CF`) — сняты с бренда.
- `--cl-pastel-mint` (`#C9F2EA`) — производный от aqua.
- Прочие мёртвые тинты (`--cl-pastel-yellow`, `--cl-pastel-green`, `--cl-mid-gray`,
  `--cl-dark-gray`, `--cl-dk2`) — **проверить `grep`-ом и удалить, если не
  используются**; серые при необходимости переиспользовать под `--chart-*`.

### Оставляем в резерве (vivid — только акценты/обводки, НЕ заливка графиков)

`--cl-ultramarine` (`#0063FF`), `--cl-purple` (`#A068FF`), `--cl-carrot`
(`#FF4517`), `--cl-coral` (`#FF0642`), `--cl-yellow` (`#CFF500`). Снабдить
комментом-правилом. Сейчас нигде не применяются — не трогаем места использования.

## Применение по графикам

Цвет назначается **по индексу сегмента** (данные приходят от больших к меньшим по
конвенции авторинга → индекс 0 = крупнейший = зелёный-герой). Сортировку **не**
добавляем (YAGNI).

| Шаблон | Макс. сегментов | Раскраска |
|---|---|---|
| `donut-chart.html` | 5 | `--chart-1..5` (зелёный + 2 доп + 2 серых) |
| `stacked-bar.html` | 4 (v1..v4) | `--chart-1..4` (зелёный + 2 доп + 1 серый); свотчи легенды — те же токены |
| `bar-chart.html` | 6 | `--chart-1..6` (зелёный + 2 доп + 3 серых) |

Для `donut` и `stacked-bar` **убираем opacity-лесенку** (`[1.0, 0.78, …]`) —
приглушённость даёт сам оттенок, полная непрозрачность у всех. Трек остаётся
`var(--bg-card)`. Анимации `m-enter` (dasharray/opacity прорисовки) не ломаем.

### Остаются зелёными (без изменений)

- `line-chart.html` — тренд одной метрики (`var(--accent)` + area-wash).
- `kpi-rings.html` — гейдж-кольца прогресса (`var(--accent)`).
- `kpi` (`.kpi-value`), `stats-row` (`.sr-value`) — одиночные крупные числа
  (`var(--accent)`, в светлой — `var(--fg-body)`; уже так).
