## Разбор референсов (что именно делать)

### 14 — service-table (`14-service-table.webp`) — ✅ СДЕЛАНО
- **Слева**: 3D-изометрическая иллюстрация (зелёное «облако-логотип» на консоли) —
  «изображение со второго слайда», с вылетом за левый край на поле точек. НЕ фото.
  → Реализовано: рыба-ассет `htmlslides/assets/service-console-3d.webp` (вырезан из
  консоли слайда-2, прозрачный фон), в шаблоне `content.image or asset(...)`,
  `.svc-image{left:-430px;top:250px;width:1040px;height:760px}` + `object-fit:contain`.
- **Панель справа**, типографика по референсу:
  - «НАИМЕНОВАНИЕ СЕРВИСА» — зелёный, bold, uppercase, перенос на 2 строки. → уже было.
  - «Описание» (правая колонка шапки) — **зелёный**, выровнен по **верхней** линии
    названия. → ПОФИКШЕНО: `.svc-desc{color:var(--accent)}` (было `--fg-body`).
  - Строки `01 / 02 / 03` (белые) | «Преимущество» (белое), разделители — тонкие
    зелёные линии; текст прижат к **верху** строки. → уже было (`align-items:flex-start`).
- Рыба-текст 01/02/03 (последовательная нумерация), не три «01».
  → ПОФИКШЕНО в `webapp/templates_api.py`: `num` → `f"{idx+1:02d}"`.

### 15 — слайд с иллюстрацией (`15-illustration.webp`)
- Заголовок + подзаголовок сверху-слева.
- **Слева**: до 5 строк «Текст» (зелёные) на тонких разделителях, прижаты к верху.
- **Справа**: светло-голубая панель-карточка (с вырезом сверху-справа) с линейной
  иллюстрацией `15-illustration-clouds-arrows.svg` (белые облака + чёрные #222 стрелки).
  Разместить панель+иллюстрацию точно как в референсе.

  #26D07C) и облака снизу-справа (`quote-clouds-green.svg`). Фон тёмный, без рамок.

## Как не терять контекст (процесс)
1. Любой приложенный референс (скрин/SVG) сразу копируем в `docs/slide-refs/` и
   фиксируем в этом файле — не оставляем «жить» только в чате.
2. Статус каждого пункта ведём в таблице выше; коммитим вместе с изменениями кода.
3. При старте сессии сверяем ветку (`git branch --show-current` → `template-picker`)
   и читаем этот файл вместо восстановления по памяти.
