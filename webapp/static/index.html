Промпт для ИИ-чата

Собери markdown-файл для генератора презентаций — из приложенного документа или нашего обсуждения. Генератор делает из каждого раздела один слайд и сам подбирает макет по форме раздела. Твоя задача — разрезать материал на разделы размером в слайд и придать каждому форму, которая ляжет на подходящий макет, не потеряв и не выдумав ни одного факта.

СТРУКТУРА
- Первая строка «# Название» — название презентации. Пиши коротко: на обложке оно идёт крупным шрифтом, всё длиннее ~40 символов уедет во вводный текст под заголовком.
- Каждый «## Заголовок» — отдельный слайд. Любой заголовок, в том числе «###», тоже станет отдельным слайдом, поэтому подзаголовков внутри раздела не делай.
- Заголовок без текста под ним слайдом не станет — не оставляй разделителей вроде «## Часть 2».
- Один раздел — одна мысль: заголовок до 50 символов и до ~700 символов текста под ним. Не помещается — раздели мысль на два раздела, а не выбрасывай.
- Оптимально 10–20 разделов; в одну презентацию берётся до 40, остальное сервис предложит собрать второй.
- Порядок разделов — как в документе.

КАК РАЗДЕЛ ЛОЖИТСЯ НА МАКЕТ
Макет генератор выбирает сам, по форме раздела. Название макета в заголовок не пиши — заголовок станет названием слайда. Форму выбирай по содержанию:
- Одна сильная мысль или фраза до 70 символов, без списка и цифр → «Цитата».
- 2 темы, у каждой заголовок и абзац → «Две карточки». 3 параллельные идеи → «Три колонки». 3–6 коротких пунктов: фичи, сервисы, тарифы → «Шесть карточек». Больше равнозначных блоков — до 3 рядов по 1–5 → «Сетка плашек» или «Сетка рамок».
- 1–2 главные цифры, у каждой единица и пояснение → «KPI». 3–8 показателей строками «значение — подпись» → «Ряд метрик». 2–4 процента выполнения, покрытия, аптайма → «KPI-кольца».
- Сравнение 3–6 величин в одной единице → «Столбчатая диаграмма». Одна метрика по периодам, 2–8 точек → «Линейный график». 2–5 долей одного целого, в сумме 100% → «Кольцевая диаграмма». Состав из 2–4 частей по группам (до 5 групп, каждая — 100%) → «Составные бары».
- Было и стало: два состояния и короткий итог вроде «−80% времени» → «До / после».
- Этапы, дорожная карта, до 5 шагов по порядку → «Таймлайн». Процесс с ветвлениями, воронка, цикл, оргструктура → «Схема».
- Один сервис и три его преимущества → «Таблица услуг».

ЦИФРЫ — ТОЛЬКО ИЗ ДОКУМЕНТА
- Каждое число, дату, процент и название стандарта из документа сохрани дословно, с единицами и суффиксами: «152-ФЗ», а не «152».
- Ни одного числа, которого нет в документе. Слово не превращай в число: «полностью» — не «100%», «половина» — не «50%», если автор так не писал.
- Не досчитывай доли до 100% и не складывай разные единицы — например, рубли со штуками сделок. Нет чисел — выбирай текстовую форму, а не диаграмму.
- Показатели пиши парами «значение — подпись»: «87% — рост конверсии».

ОФОРМЛЕНИЕ
- Плоские списки «- пункт», по одной строке до ~120 символов. Таблицы — обычные md-таблицы на 3–6 строк, в колонке одна единица измерения.
- Код — только короткими фрагментами до ~10 строк: длинный листинг на слайд не положится.
- Не используй жирный, курсив, ссылки и вложенные списки — они не переносятся. Без абзацев длиннее ~400 символов и без «воды»: каждое предложение — факт, который должен попасть на экран.

В файле — только сам markdown: никаких комментариев, пояснений, приветствий и ```-обёрток.
