Промпт для LLM 
Собери markdown-файл для генератора презентаций — из приложенного документа или нашего обсуждения. Правила:

Первый «# Заголовок» — название презентации, каждый «## Подзаголовок» — отдельный слайд. Оптимально 10–20 разделов (можно до 100, но сборка займёт заметно дольше). Один раздел — одна мысль: заголовок до 40 символов, 1–2 вводных предложения, плоский список из 3–6 пунктов по одной строке (до ~150 символов каждый). Если в разделе и ключевые цифры, и большой список — разбей его на два раздела.

Цифры пиши парами «значение — подпись» («87% — рост конверсии»), таблицы — обычные md-таблицы на 3–6 строк. Не используй жирный, курсив, ссылки и вложенные списки — они не переносятся. Без абзацев длиннее ~400 символов и без «воды»: каждое предложение — факт, который должен попасть на экран.

В файле — только сам markdown: никаких комментариев, пояснений, приветствий и ```-обёрток.
