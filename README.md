# Slides App — генерация презентаций Cloud.ru в браузере

Самодостаточное локальное веб-приложение для одного пользователя: генерация
презентаций на моделях Cloud.ru Foundation Models через браузерный интерфейс,
без Telegram. Движок (LangGraph-пайплайн, LLM-роли, рендереры, генератор HTML-дек
`htmlslides`, бренд-шаблон Cloud.ru и шрифты SB Sans) **вшит в репозиторий** —
внешние проекты для работы не нужны.

---

## Возможности

- **Три режима генерации:**
  - **Ребрендинг PPTX по шаблону** — готовый `.pptx` пересобирается по бренд-шаблону Cloud.ru → `.pptx`.
  - **Генерация PPTX без шаблона** — нативный дизайн презентации с нуля по содержимому → `.pptx`.
  - **HTML-презентация** — документ (`md` / `txt` / `docx` / `pptx`) превращается в одну
    самодостаточную HTML-деку, которую можно редактировать прямо в браузере.
- **Редактор HTML-деки в браузере:**
  - правка текста по месту (клик по тексту → редактирование);
  - **чат-правки слайда** — инструкция на естественном языке («сделай заголовок
    короче», «добавь пункт про безопасность»), и модель переписывает текущий слайд;
  - экспорт всех слайдов в **PNG (ZIP)** или скачивание самой **HTML-деки**.
- **Очередь сборок:** до 5 задач в системе (1 выполняется, до 4 ждут), с прогрессом
  по каждой; любую активную сборку можно открыть и наблюдать прогресс.
- **История** последних сборок с возможностью открыть результат заново или очистить.

## Как это работает

```
Браузер (UI)
   │  POST /api/jobs (режим + файл)
   ▼
FastAPI (webapp/) ──► фоновый поток ──► движок генерации
   ▲                                   ├─ verstai/design: LangGraph-пайплайн (graph/)
   │  WebSocket /ws/{id}               └─ htmlnew: htmlslides (Kimi-K2.6)
   └── прогресс стадий в реальном времени
```

- Приложение — **один процесс FastAPI**. Никаких Redis, Celery, Docker, S3.
- Каждая сборка запускается в фоновом потоке; прогресс движка пробрасывается в
  браузер через WebSocket (стадии: разбор → планирование → заполнение → сборка →
  проверка → готово).
- Сборки выполняются **по очереди (одна за раз)**: узкое место — общий лимит
  запросов аккаунта Cloud.ru (RPS), а не процессор, поэтому параллельный запуск
  не ускорил бы, а лишь упёрся бы в лимит. До 4 задач ждут в очереди.
- **HTML-режим** строится на Kimi-K2.6 через Cloud.ru FM; чат-правки переиспользуют
  тот же движок — модель переписывает один `<section>` слайда с соблюдением
  бренд-правил Cloud.ru.
- Готовый файл (`.pptx` или `deck.html`) и PNG лежат в рабочей папке сессии
  (по умолчанию во временной директории ОС; путь можно переопределить через
  переменную окружения `SLIDESBOT_WORKDIR`).

## Структура репозитория

```
webapp/        FastAPI-приложение: маршруты, очередь, прогресс, редактор, чат, статика
graph/         LangGraph-пайплайн (режимы verstai / design)
llm/           клиент Cloud.ru FM, роли и промпты
worker/        запуск пайплайна и канал прогресса
htmlslides/    генератор HTML-деки (режим htmlnew, Kimi) + шаблоны, шрифты, бренд-правила
renderers/     рендереры слайдов
scripts/       вспомогательные утилиты движка (рендер PNG для vision-QA)
schemas/       Pydantic-модели
skill_assets/  бренд-шаблон Cloud.ru (.pptx) и справочные материалы
bot/           только config.py + logging_setup.py (Telegram не используется)
tests/         автотесты приложения (без обращений к сети)
```

## Установка

Требуется **Python 3.10+**.

```bash
# 1. Клонировать репозиторий
git clone https://github.com/glmelnik96/SLIDES_APK.git
cd SLIDES_APK

# 2. Виртуальное окружение
python -m venv .venv
# Windows:
.venv\Scripts\activate
# macOS / Linux:
source .venv/bin/activate

# 3. Зависимости приложения и движка (всё вшито в репозиторий)
pip install -e ".[dev]"

# 4. Браузер для рендера PNG (headless Chromium)
playwright install chromium

# 5. Ключ Cloud.ru
cp .env.example .env        # Windows: copy .env.example .env
#   затем впишите в .env свой CLOUDRU_API_KEY
```

`.env` (единственное обязательное поле):

```dotenv
CLOUDRU_API_KEY=ваш-ключ-cloud.ru
# необязательно — переопределить базовый URL Cloud.ru FM:
# CLOUDRU_BASE_URL=https://foundation-models.api.cloud.ru/v1
```

## Запуск

```bash
python -m webapp
# или: ./start.sh  (macOS/Linux)   |   start.bat  (Windows)
```

Откройте в браузере **http://127.0.0.1:8000**

Дальше: выберите режим → загрузите файл → «Создать презентацию» → наблюдайте
прогресс. Для PPTX-режимов по завершении доступна кнопка скачивания `.pptx`;
для HTML-режима автоматически откроется редактор с чатом и экспортом.
